The supervisor tree

One tree you can follow.

See the four views
01

The tree, not the chat log

Every agent hangs off a named supervisor with a permanent id. A spine runs through them, so you always know what is working, what finished, and what is stuck.

02

Four views, one system

Tree for the spine. Mux for density. Comms for the wire between agents. Alarms for the one screen that is allowed to shout. Nothing else moves.

03

Cleanup is not a button

Finished sessions close themselves. Orphans get swept. The tree returns to idle on its own, so the next job starts from zero.

Why it feels different

Square inside, soft outside.

01

Data is square

Pixels, dither, status dots, meters. Hard edges, integer cells, no blur, no shadow. The data is honest, so it looks honest.

02

Chrome is soft

Buttons, inputs, chips, panels are pills. The tension between the square data and the soft chrome is the whole brand.

03

Hierarchy is value

No shadows, no glass, no glow. Depth is a step from black to near-black. If it needs a shadow to read, it is in the wrong place.

04

One loud screen

Alarms is the only screen allowed to shout, and it only shouts when a human has to decide. Everything else stays quiet.
